AWS Key Tutorial — Screenshot Assets
=====================================

Drop PNG/JPG screenshots into this folder with the exact filenames below.
The tutorial page auto-detects and shows them. If missing, it falls back
to AWS official docs images (or shows a placeholder).

Recommended size: max 1600px wide, keep under 500KB (compress with
tinypng.com or squoosh.app for fast page load).

Required files:
---------------

  step-2-search-service.png     — AWS Console with "Location Service"
                                   searched, showing the service card
                                   or the sidebar with "API keys" menu

  step-3-region-selector.png    — Top-right region dropdown showing
                                   "Asia Pacific (Singapore) ap-southeast-1"
                                   (the screenshot you already shared)

  step-4-create-key-form.png    — "Create API key" form with Name,
                                   Description fields filled in

  step-5-restrictions.png       — Client restrictions section:
                                   Referer allowlist + Expiration date

  step-7-copy-key.png           — Success screen after key creation,
                                   with "Show API key value" / Copy button

Tips:
-----
- Redact real key values before uploading (blur or replace with dummy)
- Use consistent browser theme (light or dark) across all screenshots
- Crop tight around relevant UI, avoid extra whitespace
- PNG for UI screenshots, JPG only for photo-heavy content

Once uploaded, hard-refresh the tutorial page (Cmd/Ctrl + Shift + R)
to bypass browser cache.
